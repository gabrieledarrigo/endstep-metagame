Text and neutrals

The neutrals have a warm bias so they sit with the card art. Contrast is measured against the card surface, #fcfcfb. Body text needs 4.5:1. Marks and large text need 3:1.

Endstep's data starts on 2026-09-05, so a 30-day window returns fourteen empty days. Draw those points as a gap, not as zero.

Quotes and asides use --text-600 with a --baseline rule. --text-400 sits below the body-text threshold. Use it for axis ticks and captions only.

Action colours

Primary is dark enough for body-size link text at 6.46:1 and for --text-inverse button labels at 6.63:1. The lighter #2a78d6 is held back for chart marks, which only need 3:1. Secondary is a warm near-black on an outline. A second saturated colour would compete with the series palette.

Part two. Components

Panel

The container for every block on the page. There is one panel style. Sections do not nest panels inside panels.

Surface --surface. Border 1px --edge. Radius 10px. Padding 22px, reduced to 15px inside a deck card. No shadow. Elevation is not used on this page, so a border is enough to separate a panel from the background.

Buttons

Three variants. The page uses fewer of them than this sheet shows, so each one below names where it actually appears.

Primary is the retry control in FR-9. It is the only primary button on page 1. Secondary is the outbound link on a deck card, styled as a button where it needs a hit target. Ghost is for low-weight toggles. Disabled drops opacity to .45 and removes the hover change. Padding is 9px by 17px, radius 7px, label 14px 600. Focus shows a 2px --primary ring at 2px offset.

Window selector

A segmented control, one row, five options. Selection applies immediately. There is no apply or reset step because the page has one filter.

Track --surface with a 1px --edge border, radius 8px, 3px inner padding. Selected fills with --primary and uses --text-inverse. State is carried by aria-pressed, so it reaches assistive technology rather than only showing as a fill. Labels use tabular numerals so the segments do not resize between windows. Below 400px the control scrolls horizontally rather than wrapping to two rows.

Fills are the standard Magic mana colours. Letters are #1a1714 and clear 4.5:1 on every fill, from 9.50:1 on red to 17.01:1 on white. The fills themselves sit between 1.02:1 and 1.83:1 against the surface, so the 1px ring at rgba(11,11,11,.22) is what makes the pip visible at all. It is structural, not decorative.

The letter is also what satisfies NFR-6. Colour never carries identity alone. The group additionally carries a visually hidden label, so a screen reader announces Colours: white, blue, black rather than reading three separate letters.

Direction is carried by the triangle, not by the colour, per NFR-6. Colour reinforces it: --up #006300 at 10.1:1 and --down #d03b3b at 4.68:1, both above the 4.5 threshold for text. Tooltip values are ordered by value, not by series index, so the row under the cursor is easy to find. Labels wear --text-600 and values --text-900. The swatch carries the series colour, never the text, which is the rule from the design language.

Legend entries are buttons and toggle their series. A hidden series keeps its colour and adds a strike-through at .4 opacity, so the toggle state does not rest on opacity alone.

Loading, error and empty

FR-9. Three states for every data-backed section.

Skeleton

The skeleton matches the real card box for box, including the art aspect ratio. That is the point of choosing it: 24 cards with images would otherwise shift the whole page when they arrive. The pulse is 1.5s and stops under prefers-reduced-motion. The container carries aria-busy="true".

Error and empty

The metagame could not be loaded

Endstep did not respond. The data is cached for five minutes, so a retry usually works.

No decks in this window

The 1 day window has no registrations yet. Try a longer window.

Errors say what happened and what to do. They do not apologise and they do not show a status code as the headline. A 429 gets its own message naming the rate limit, per FR-9. The empty state offers the action that resolves it rather than only stating the problem.

Part three. Tokens

Tokens

Paste into the single HTML file. Use the roles in the stylesheet, not raw hex.

:root {
  /* surfaces */
  --background:    #f9f9f7;   /* page behind the cards */
  --surface:       #fcfcfb;   /* cards, table, chart area */
  --edge:          rgba(11,11,11,.10);

  /* text */
  --text-900:      #0b0b0b;   /* 19.17:1  headings, values */
  --text-600:      #52514e;   /*  7.73:1  body text, quotes */
  --text-400:      #898781;   /*  3.50:1  axis, caption, Other */
  --text-inverse:  #ffffff;   /*  6.63:1  on primary fills */

  /* lines */
  --rule:          #e1e0d9;   /* gridlines, row separators */
  --baseline:      #c3c2b7;   /* chart baseline, quote rule */

  /* action */
  --primary:       #1c5cab;   /*  6.46:1  links, filled buttons */
  --primary-wash:  #eaf1fb;   /* hover, selected, callout */
  --secondary:     #3f3f3c;   /* 10.29:1  outline buttons */

  /* chart series, fixed order, no cycling */
  --s1:#2a78d6; --s2:#eb6834; --s3:#1baf7a; --s4:#eda100;
  --s5:#e87ba4; --s6:#008300; --s7:#4a3aa7; --s8:#e34948;

  /* sequential blue, bars and heatmaps */
  --seq-100:#cde2fb; --seq-200:#9ec5f4; --seq-300:#6da7ec; --seq-400:#3987e5;
  --seq-500:#256abf; --seq-600:#184f95; --seq-700:#0d366b;

  /* type */
  --sans: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
